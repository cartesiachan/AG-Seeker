# AG-Seeker

Room for many exploration related to AI tools, methods, and reusable agent skills.

## Central Skills Library

Seluruh skill di repositori ini mengikuti format standar **`skills/<nama-skill>/SKILL.md`** (*progressive disclosure*) agar mudah dibaca oleh **Antigravity**, **Claude Code**, **Codex**, **OpenCode**, dan agent lainnya tanpa duplikasi di setiap repo proyek.

| Skill | Deskripsi | Lokasi |
|---|---|---|
| `webp-catalog-assets` | Pipeline membuat hero banner (`1280×720`), kartu produk seragam (`800×600`), dan thumbnail blog berformat WebP ringan tanpa Canva | [SKILL.md](skills/webp-catalog-assets/SKILL.md) |
| `laravel-storefront` | Standar wajib Laravel storefront/web-to-print (migrasi, RBAC, mobile header & `4:3` zoomable image, dynamic settings, media cleanup, Chromium check) | [SKILL.md](skills/laravel-storefront/SKILL.md) |

## Cara Pakai di Proyek Lain

- **Di Antigravity:** Skill di atas juga tersimpan di Skill Store global Antigravity sehingga otomatis tersedia di percakapan mana pun.
- **Di Repo Proyek (contoh `web-percetakan`):** Cukup cantumkan referensi skill yang relevan di `AGENTS.md` proyek tersebut—tidak perlu menyalin ulang folder skill umum kecuali proyek tersebut harus berdiri terisolasi total.

> Lihat [AGENTS.md](AGENTS.md) untuk aturan pemeliharaan dan penambahan skill baru dari hasil eksplorasi.
